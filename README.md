该项目由 ChinaNovaQwQ（[User:ChinaNovaQwQ](https://wiki.backroomszh.org/User:ChinaNovaQwQ)）维护，是一套基于 MediaWiki API 制作的一站式站点管理平台。

## 优势

* 界面~~十分甚至九分的美观~~采用 Fluent UI 设计，界面整体统一。
* 较直接访问网站，使用平台的速度略快。

## 但是……

由于该项目处于较早期的开发阶段，故代码**极其不稳定**且难以维护。

若您发现该项目中存在bug，欢迎捉虫并提出进一步的修改意见！
