## 对于普通用户

如果您只是想要尝试使用应用进行审核并且不需要插件功能的话，只需要在最新的 Release 中下载 .exe 版本即可运行。

### 注册机器人密码

如果您打算在 [Miraheze 后室中文](https://wiki.backroomszh.org)上使用本功能，则需要先打开 Special:BotPasswords 页面，随后找到“创建新的机器人密码”，为机器人命名之后，进入授权页面，勾选这些：

* 大量操作（机器人）访问权限
* 编辑存在的页面
* 创建、编辑和移动页面

其它不进行更改，随后点击“创建”，进入新页面后记住您的机器人密码和登录账号，并保存到**安全的地方**。**永远不要保存到网盘、桌面等易于被他人访问的地方。**最好将其记录在纸条、加密文件夹或自己的个人U盘等不容易被发现的地方，并确保其完整性。

### 获取应用

进入项目主页后，点击右侧的“Release”，找到最新的发行版，下载对应的.exe文件（切记不要下载source.zip）。

理论上来说，其应当 **可以且只可以** 在 Windows 操作系统上运行，且至少需要是 Windows 10 22H2 版及其之后的版本。

安装完成后，最好在英文目录下启动本应用（如 `E:\MirahezeBkrCNPlatform`），然后点击进入设置，再转到设置，找到自动化操作测试，键入您的账户信息。**截止到目前的版本，仓库还没有实现加密存储，故请确保您的计算机安全并不要外泄您的机器人密码。**

## 对于开发者

如果您想要扩展功能、编写插件等，请参阅本节内容。

### 在开始之前

在启动项目开发之前，您需要确保您已安装这些应用：

* Python 3.10+（推荐Python 3.11~3.12.1，更为激进可以使用Python 3.13.3）
* Git（非必须，但更为方便）
* （可选）Miraheze 账户，并注册机器人密码。

### 注册机器人密码

如果您打算在 [Miraheze 后室中文](https://wiki.backroomszh.org)上使用本功能，则需要先打开 Special:BotPasswords 页面，随后找到“创建新的机器人密码”，为机器人命名之后，进入授权页面，勾选这些：

* 大量操作（机器人）访问权限
* **编辑存在的页面**
* **创建、编辑和移动页面**

其它不进行更改，随后点击“创建”，进入新页面后记住您的机器人密码和登录账号，并保存到**安全的地方**。**永远不要保存到网盘、桌面等易于被他人访问的地方。**最好将其记录在纸条、加密文件夹或自己的个人U盘等不容易被发现的地方，并确保其完整性。

### 下载项目

首先将项目克隆到本地：

```bash
git clone https://github.com/RainPurNova418/miraheze-bkr-cn-platform.git
cd miraheze-bkr-cn-platform
```

随后，为了操作的简明性，您需要创建一个虚拟环境以确保代码稳定运行：
```bash
python -m venv venv
venv\Scripts\activate
```

最后，安装依赖：
```bash
pip install -r requirements.txt
```

**上述操作请在同一终端页面中完成。**

在此之后，您可以用您喜爱的任何方式打开并启动 main.py，进行调试并修改代码。
